# 双协议修复复核记录

本次针对 v2.2.10 的双协议缺陷复核，覆盖管理界面、协议端口检测、核心生命周期与订阅输出。验证在本地隔离环境执行，没有对线上 VPS 执行重装或卸载。

| 范围 | 覆盖内容 | 验证方式 |
| --- | --- | --- |
| 首页卡片 / 表格 | Xray、sing-box TCP、UDP、TCP+UDP；最大五位数端口 | Chrome CDP，320 / 375 / 768 / 1024 / 1440px |
| 管理抽屉 | 协议显示、sing-box 启动/停止、配置查看、重装表单 | CDP 操作与 HTTP handler 回归测试 |
| 重装默认值 | 保留核心、已启用协议、端口、SNI、域名 | CDP，包含 UDP 单节点 |
| 单端口 NAT | 随机选端口没有可选值时返回空值，避免死循环 | CDP |
| 检测请求 | TCP/UDP 同时提交、裸端口兼容 TCP、相同端口不同协议不合并 | CDP、模型与探测器测试 |
| 监听判定 | TCP LISTEN、UDP UNCONN；ss、netstat、/proc 的十六进制端口 | 探测器测试 |

| 异步界面 | 慢请求不能覆盖新目标；失败不保留旧成功结果；重新打开使用正确接口；探针刷新不重复触发检测 | CDP |
| 核心切换 | Xray → 双协议 → 双协议改端口 → UDP → TCP → 双协议 → Xray | handler + 执行器桩；检查清理发生在安装之前 |
| 清理脚本 | 两种核心的二进制、服务、配置、证书、备份与旧端口规则；保留 Agent | 临时文件系统执行实际 shell，服务管理和防火墙命令使用桩 |

| 服务状态 | 按 Xray / sing-box 独立上报；两个协议一起更新；兼容缺少新字段的旧 Agent | Collector 与 Manager 测试 |
| 订阅 | 切换后只包含当前协议；Mihomo / sing-box 保留双节点；Shoes 跳过不支持的 Hysteria2 | 重装组合测试直接渲染真实生成的分享链接 |
| 真实核心 | sing-box 1.12.0 分别校验并运行 TCP / UDP / 双协议配置 | `TestSingBoxRuntimeMatrix` |
| Hysteria2 | 真实客户端经 QUIC 认证，再通过 SOCKS 入口请求本地 HTTP 目标 | `TestSingBoxRuntimeMatrix` |

最终浏览器审计记录共 91 项，无横向溢出、运行时异常或控制台错误。另检查新弹窗的键盘焦点、Tab 循环与 Escape 关闭。

常规验证：

```sh
CGO_ENABLED=0 go test ./...
npm --prefix web run build
```

真实核心测试为显式启用，常规 CI 不下载额外代理二进制：

```sh
QY_TEST_SINGBOX_BINARY=/absolute/path/to/sing-box \
  CGO_ENABLED=0 go test ./internal/singbox -run TestSingBoxRuntimeMatrix -count=1 -v
```

TCP 真实核心测试覆盖配置校验和监听启动；本次未执行需要外部 Reality 伪装站点的真实 VLESS 握手。Hysteria2 认证代理测试使用本地目标，不依赖公网 DNS 或外部站点。真实 systemd / OpenRC 主机上的提权卸载和云厂商安全组仍需在测试 VPS 上验收。

旧 Agent 不具备 `sing_box_active` 字段，需要升级 Agent 才能实时上报 sing-box 的外部启动/停止变化。面板自身执行服务操作后会同步更新同核心的全部节点。

## v2.2.11 发布前界面复核

- 简化重装说明和证书说明，去掉重装提示的成功图标与协议选项的重复边框；保留服务中断、安装失败及证书身份验证的限制。
- 双协议端口在桌面并排、手机纵向显示，随机端口按钮使用相同样式；SNI 独立一行。
- 合并手动 DNS 说明，删除高位端口降低阻断风险的无依据建议。
- 日志只展示本地已知参数及服务端返回的内容，不再补写安装步骤；安装成功显示“安装完成”，不宣称已通过代理连通性验证。
- 最终构建重跑 91 项 CDP 检查；另对 320 / 1440px 明暗主题执行 4 组表单检查，覆盖双协议提交、安装中禁止关闭与 DNS 部分失败提示。浏览器 API 使用测试数据，未向真实 VPS 发起安装。
- `kill-ai-slop` 扫描覆盖 56 个前端文件，命中由 302 处降至 301 处。主要保留项为真实状态颜色、圆形状态点和开关、日志等级识别，以及 IP / 端口 / 代码 / 配置的等宽字体。其余改动来自人工复核，扫描器不识别这些中文文案和表单层级问题。
